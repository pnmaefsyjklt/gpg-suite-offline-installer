## About

GPG Suite is a comprehensive macOS email encryption toolkit that integrates OpenPGP encryption into Apple Mail, Spotlight, and the system Services menu. Create and manage GPG keys, encrypt and sign emails, and verify signed messages from others with a native macOS experience. GPG Suite brings professional-grade email privacy to the Mac platform with minimal configuration.

## Common Problems & Limitations

- **macOS Only** — macOS-specific GPG integration; Windows users need Gpg4win
- **Commercial License** — GPG Suite currently requires paid license after trial
- **Learning Curve** — Public-key cryptography concepts require dedicated learning
- **Recipient Dependency** — Email encryption only works if recipients also have GPG keys
